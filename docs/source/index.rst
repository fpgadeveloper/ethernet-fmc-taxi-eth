Ethernet FMC Taxi Ethernet Reference Designs
============================================

This is the documentation for the Taxi Ethernet reference designs for the `Ethernet FMC`_
and `Robust Ethernet FMC`_: four gigabit Ethernet ports built from the open-source
`Taxi`_ RGMII MAC and AMD AXI DMA, with no separately-licensed AMD IP.
